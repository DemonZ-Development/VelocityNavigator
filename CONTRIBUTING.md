# Contributing to VelocityNavigator

Thanks for taking the time to contribute. VelocityNavigator is an open-source project maintained by **[DemonZ Development](https://demonz.org)**, and we welcome contributions of any size.

## How Can I Contribute?

### Reporting Bugs
We track bugs as GitHub issues. When creating a bug report, include as much detail as possible: the Velocity version, the VelocityNavigator version, the relevant section of `navigator.toml`, and any logs or stack traces.

### Suggesting Enhancements
We track feature requests as GitHub issues. Describe the problem you are trying to solve and the behavior you expect; concrete examples and proposed config shapes help.

### Pull Requests
- Fork the repository and create your branch from `main`.
- If you add code that should be tested, add tests covering it.
- Ensure the test suite passes (`mvn verify`).
- Follow the existing code style.
- Keep commits focused: one logical change per branch makes review faster.
